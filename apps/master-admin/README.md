# Master admin dashboard

This app is the single operational control panel for the platform. It is responsible for medical-center verification, global audit review, and capacity analytics for the shared Medico system.

## What it does

- Reviews hospital registrations waiting for verification
- Approves or rejects pending hospitals and their legal documents
- Displays recent system audit activity
- Shows aggregate bed and hospital metrics across the verified network

## Local setup

Start the backend with a valid `DATABASE_URL`, then run:

```sh
pnpm --filter master-admin dev
pnpm --filter master-admin build
```

The dashboard is served on port `5174` and expects the backend at `http://localhost:5000/api` by default.

If your API is hosted elsewhere, point the client at the correct origin before startup:

```sh
VITE_API_BASE_URL=http://localhost:5000/api pnpm --filter master-admin dev
```

## Admin flow

The app signs in through the backend admin session endpoint. Once authenticated, the dashboard shows three main sections:

- Verification queue
- System audit feed
- Analytics panel

Approval and rejection actions update the pending hospital state in a transaction that also records the global audit event. Legal document previews are opened through short-lived signed URLs generated by the backend.

## Security model

- The master admin session is cookie-based and managed by the browser.
- The backend validates the signed session and keeps the secret server-side.
- The frontend never contains backend credentials or Supabase secrets.
- The app depends on the backend allowlist and CORS configuration for browser-to-API trust.
